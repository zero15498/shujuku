# UI 七个 Tab 字段清单

本文整理当前现役主弹窗的 7 个一级 Tab，入口由 `src/presentation/pages/main-popup.ts` 组装：

1. 仪表盘
2. 更新
3. API
4. 表格
5. 核心功能
6. 数据管理
7. 高级工具

说明：

- “字段”按用户可见的输入框、下拉框、单选/复选框、动态列表、状态展示和主要操作按钮整理。
- 动态列表类控件，例如“规则行”“提示词段落”“表格选择项”，按单行或单段包含的字段说明。
- 本清单只覆盖主弹窗 7 个一级 Tab；可视化表格编辑器是另一个独立窗口，不纳入本文。

## 1. 仪表盘

来源：`src/presentation/pages/main-popup-status.ts`

### 数据库状态

| 字段 / 控件 | 类型 | 用户层功能简述 |
|---|---|---|
| 上下文总层数 | 状态展示 | 显示当前聊天中参与统计的 AI 回复楼层数量。 |
| 数据库更新状态 | 状态展示 | 显示数据库当前是否正常、是否正在更新、是否有异常。 |
| 表格名称 | 状态表列 | 显示每张数据库表的名称。 |
| 更新频率 | 状态表列 | 显示该表按多少楼层间隔触发更新。 |
| 未记录楼层 | 状态表列 | 显示该表还有哪些 AI 楼层未写入数据库。 |
| 上次更新 | 状态表列 | 显示该表最近一次更新到哪个楼层或时间点。 |
| 下次触发 | 状态表列 | 显示该表预计什么时候会被自动更新。 |
| 下一次更新 | 状态展示 | 汇总显示整体下一次自动更新的判断结果。 |

| 字段 / 控件 | 类型 | 用户层功能简述 |

### 手动更新表选择

| 字段 / 控件 | 类型 | 用户层功能简述 |
|---|---|---|

### 核心功能开关

| 字段 / 控件 | 类型 | 用户层功能简述 |
|---|---|---|
| 启用自动更新 | 复选框 | 开启后，聊天推进到满足条件时自动更新数据库。 |

| 表格存储模式：原生模式 | 单选项 | 使用 JSON/DSL 方式存储和更新表格。 |
| 表格存储模式：SQLite 模式 | 单选项 | 使用内存 SQLite 和 SQL 语句存储、查询、变更表格。 |
